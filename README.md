Hangman Game - Python
Project Description

This is a terminal-based Hangman game developed using Python as part of the Datheon Python Internship.

The player must guess a hidden English word one letter at a time within six incorrect attempts.

Features
Random word selection
Six incorrect attempts
ASCII Hangman graphics
Tracks previously guessed letters
Prevents duplicate guess penalties
Input validation
Win and game-over messages
Technologies Used
Python 3
Random module
Sets, loops, and conditional statements
How to Run
Install Python 3.
Download or clone this repository.
Open a terminal in the project folder.
Run the following command:
bash
python hangman.py
